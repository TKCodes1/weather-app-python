# Python Weather app

A Python application that takes a city name from the user and retrieves real-time weather data using the Open-Meteo API.

---

## 📙Features:
- User can input any city name
- Converts the city into longitude and latitude for API
- Retrieves live weather from Open-Meteo
- Displays temperature, precipitation, and wind speeds.

---

## 🧠What I learned and used:
- JSON data
- APIs
- User input
- String formatting
- Dictionaries
- External data sources
- HTTPS requests

---

## 🧰Tools used:
- Python
- Open-Mateo weather API
- Open-Mateo geocoding API
- requests library

---
## ▶️How to run:

1. Install Python
2. Install the requests library:

```bash
pip install requests
```

3. Run the program:

```bash
python main.py
```
